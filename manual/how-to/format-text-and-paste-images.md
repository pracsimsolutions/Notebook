Wherever the Notebook lets you write more than a line of text, a formatting toolbar sits above the writing area. You will see it in the written sections of [Scoping](../tabs/scoping.md), in [Notes](../tabs/notes.md), in the description of a card on the [Board](../tabs/board.md), in the Observations, Analysis and Next steps sections of [Validation](../tabs/validation.md), and when you edit text on a shape in [Canvases](../tabs/canvases.md).

Select some text and click a button to format it. Click the button again to remove the formatting. Hover over any button to see its name.

## The toolbar buttons

From left to right:

| Button | What it does |
| --- | --- |
| **B** | Bold (Ctrl+B) |
| **I** | Italic (Ctrl+I) |
| **U** | Underline (Ctrl+U) |
| **S** | Strikethrough |
| **A** (text color) | Opens the text color choices |
| **A** (highlight) | Opens the highlight color choices |
| Bullet | Turns lines into a bulleted list |
| **1.** | Turns lines into a numbered list |
| Three line icons | Align left, center or right |
| **H1**, **H2**, **H3** | Make the line a large, medium or small heading |
| **Link** | Adds a web link to the selected text |
| `</>` | Marks the selected text as inline code |
| **Image** | Inserts an image from a file |

## Colors and highlights

Click the text color button to open a row of colored squares. Pick one to color the selected text. The choices are Default, Red, Orange, Yellow, Green, Teal, Blue, Purple and Pink. Choose Default to return to the normal text color.

The highlight button works the same way and paints a soft background behind the text. The choices are None, Yellow, Red, Orange, Green, Blue, Purple and Pink. Choose None to clear the highlight.

To close either row without choosing, click anywhere else.

## Headings

Click H1, H2 or H3 with the cursor on a line to turn that line into a heading. Click the same heading button again to turn it back into normal text. If the line is part of a list, the list formatting is removed when you apply a heading.

## Inline code

Select some text and click the code button to show it in a monospaced font with a light box behind it. With the cursor inside code, click the button again to remove it. The button does nothing if you have not selected any text.

## Links

1. Select the text you want to link.
2. Click **Link**. A small box appears next to the button, with "https://" already filled in.
3. Type or paste the address and confirm it.

To open a link while editing, hold Ctrl and click it. Plain clicks place the cursor so you can edit the link text. Hover over a link to see its full address and a reminder to use Ctrl+click.

## Add images

You can add an image in two ways:

- **Paste it.** Copy an image (for example a screenshot) and paste it into the writing area with Ctrl+V. It appears at the cursor.
- **Pick a file.** Click **Image**, choose a picture file, and it is inserted at the cursor.

Images are stored with your Notebook, so they are included when you [export your data](export-and-import.md).

In Notes and Board card descriptions, large images are scaled down to fit the width of the writing area.

> [!NOTE]
> When you paste text, the Notebook pastes it as plain text and drops the formatting it had where you copied it. Use the toolbar to format it again.

### Select, delete and enlarge images

- **Select an image** by clicking it. In Notes and Board card descriptions it gets a colored outline.
- **Delete an image** by selecting it and pressing Delete or Backspace.
- **Enlarge an image** by double-clicking it. It opens over the whole Notebook on a dark background, scaled to fit the window. Click anywhere, or press Esc, to close it.

There is no way to resize an image by dragging.

## Undo

FlexSim can intercept Ctrl+Z before the Notebook sees it, so do not rely on it. The Undo and Redo buttons at the top of each tab step back through actions such as adding or deleting items. They do not step through individual typing.
