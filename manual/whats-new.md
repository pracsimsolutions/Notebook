## 26.0

- Notebook is now open source under the MIT license.
- The Validation tab records each model run with a snapshot of your parameters and performance
  measures, the manual changes you made, and your observations, analysis and next steps.
- Fixed the parameter snapshot so it reports each parameter's real value instead of always
  reporting 2.
- Notebook ships as a standalone installer for FlexSim 2026.
